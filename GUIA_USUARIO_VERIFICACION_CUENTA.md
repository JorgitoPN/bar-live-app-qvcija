
# Guía de Usuario: Verificación de Cuenta con Token

## 🎯 ¿Qué es la verificación de cuenta?

La verificación de cuenta es un proceso de seguridad que confirma que tu dirección de correo electrónico es válida y te pertenece. Esto ayuda a proteger tu cuenta y garantiza que puedas recuperar el acceso si olvidas tu contraseña.

## 📱 Cómo verificar tu cuenta

### Paso 1: Regístrate en BarLive
1. Abre la app BarLive
2. Toca en "Regístrate gratis"
3. Completa el formulario con:
   - Tu nombre completo
   - Tu correo electrónico
   - Una contraseña segura
4. Acepta los términos y condiciones
5. Toca "Crear cuenta"

### Paso 2: Revisa tu correo
1. Abre tu aplicación de correo electrónico
2. Busca un correo de **BarLive** (noreply@barliveapp.es)
3. El asunto será: "🎉 Verifica tu cuenta de Barlive"
4. **Importante:** Si no ves el correo, revisa tu carpeta de spam

### Paso 3: Copia el código
1. Abre el correo de BarLive
2. Verás un código de **6 dígitos** en grande
3. Copia este código (ejemplo: 123456)

### Paso 4: Introduce el código en la app
1. La app te mostrará 6 campos para introducir el código
2. Escribe o pega el código de 6 dígitos
3. El código se validará automáticamente
4. Toca "Verificar cuenta"

### Paso 5: ¡Listo!
1. Verás un mensaje de confirmación
2. Tu cuenta está ahora verificada
3. Puedes iniciar sesión y disfrutar de BarLive

## ⏰ Tiempo de expiración

- El código de verificación **expira en 1 hora**
- Si el código expira, puedes solicitar uno nuevo
- No hay límite de veces que puedes solicitar un nuevo código

## 🔄 ¿Cómo solicitar un nuevo código?

Si tu código expiró o no lo recibiste:

1. En la pantalla de verificación, toca "Reenviar código"
2. Se enviará un nuevo código a tu correo
3. Revisa tu bandeja de entrada
4. Introduce el nuevo código

## ❓ Preguntas Frecuentes

### ¿Por qué no recibo el correo?

**Posibles razones:**
- El correo está en tu carpeta de spam
- Escribiste mal tu dirección de correo
- Tu proveedor de correo está bloqueando emails automáticos
- Hay un problema temporal con el servicio de correo

**Soluciones:**
1. Revisa tu carpeta de spam o correo no deseado
2. Añade noreply@barliveapp.es a tus contactos
3. Espera unos minutos y solicita un nuevo código
4. Contacta con soporte si el problema persiste

### ¿Qué hago si el código no funciona?

**Verifica que:**
- Estás introduciendo el código correcto (6 dígitos)
- El código no ha expirado (1 hora de validez)
- No has usado ya ese código
- Estás usando el código más reciente si solicitaste varios

**Si sigue sin funcionar:**
- Solicita un nuevo código
- Contacta con soporte: soporte@barliveapp.es

### ¿Puedo verificar mi cuenta más tarde?

Sí, pero con limitaciones:
- No podrás iniciar sesión hasta verificar tu cuenta
- Tu cuenta permanecerá inactiva
- Puedes solicitar un código de verificación en cualquier momento desde la pantalla de login

### ¿Es seguro este método?

**Sí, es muy seguro:**
- Los códigos son de un solo uso
- Expiran en 1 hora
- Se envían solo a tu correo electrónico
- Están encriptados en nuestra base de datos
- No se pueden reutilizar

### ¿Qué pasa si alguien más solicita un código para mi email?

**No hay problema:**
- Solo tú tienes acceso a tu correo electrónico
- Sin el código, nadie puede verificar la cuenta
- Los códigos antiguos se invalidan al solicitar uno nuevo
- Recibirás una notificación por correo de cada solicitud

## 🆘 Soporte

Si tienes problemas con la verificación:

**Email:** soporte@barliveapp.es

**Incluye en tu mensaje:**
- Tu dirección de correo electrónico
- Descripción del problema
- Capturas de pantalla si es posible
- Hora aproximada del intento

**Tiempo de respuesta:** 24-48 horas

## 💡 Consejos

### Para recibir el correo más rápido:
- Asegúrate de tener conexión a internet estable
- Usa una dirección de correo confiable (Gmail, Outlook, etc.)
- Añade noreply@barliveapp.es a tus contactos

### Para evitar problemas:
- Verifica tu cuenta inmediatamente después de registrarte
- No cierres la app mientras esperas el código
- Guarda el código en un lugar seguro si no lo vas a usar inmediatamente
- No compartas tu código con nadie

### Para una experiencia óptima:
- Usa la misma dirección de correo que usaste al registrarte
- Introduce el código completo antes de tocar "Verificar"
- Si tienes dudas, lee las instrucciones en pantalla
