COPIA Y PEGA ESTOS COMANDOS EN LA TERMINAL (en orden):

═══════════════════════════════════════════════════════════════════════════════
PASO 1: LIMPIAR CACHÉ DE GRADLE
═══════════════════════════════════════════════════════════════════════════════

cd android && ./gradlew clean && ./gradlew --stop && cd ..

═══════════════════════════════════════════════════════════════════════════════
PASO 2: VERIFICAR DEPENDENCIAS DE EXPO
═══════════════════════════════════════════════════════════════════════════════

npx expo install --check

═══════════════════════════════════════════════════════════════════════════════
PASO 3: COMPILAR APK DE PRODUCCIÓN
═══════════════════════════════════════════════════════════════════════════════

eas build --platform android --profile production

═══════════════════════════════════════════════════════════════════════════════
LÍNEA A AÑADIR EN android/app/proguard-rules.pro (después de línea 37)
═══════════════════════════════════════════════════════════════════════════════

-keep interface expo.modules.kotlin.** { *; }

═══════════════════════════════════════════════════════════════════════════════
COMANDO TODO-EN-UNO (ejecutar después de actualizar proguard-rules.pro)
═══════════════════════════════════════════════════════════════════════════════

cd android && ./gradlew clean && ./gradlew --stop && cd .. && npx expo install --check && eas build --platform android --profile production
