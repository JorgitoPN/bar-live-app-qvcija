
# Bar Live App

<!-- This is a comment in the README file -->

A React Native + Expo 54 application for discovering and managing bars, clubs, and nightlife venues.

## Features

- Explore local venues with interactive maps
- Social features with posts, comments, and moments
- Event management and job listings
- User profiles and authentication
- Admin panel for venue management

## Getting Started

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Run on specific platforms
npm run ios
npm run android
npm run web
```

## Project Structure

- `/app` - Main application screens and routing
- `/components` - Reusable UI components
- `/contexts` - React Context providers
- `/utils` - Utility functions and helpers
- `/styles` - Common styles and theming

## Technologies

- React Native
- Expo 54
- Expo Router (file-based routing)
- Supabase (backend)
- TypeScript
