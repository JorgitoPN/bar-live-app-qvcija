═══════════════════════════════════════════════════════════════════
WHY THIS WORKS
═══════════════════════════════════════════════════════════════════

The Problem:
• R8 (Android's code shrinker) removes "unused" classes
• Expo modules use reflection to load classes dynamically
• R8 doesn't detect dynamically loaded classes as "used"
• R8 removes them → Build fails with "Missing class" error

The Solution:
• ProGuard rules tell R8 to KEEP specific classes
• We keep all Expo modules, Kotlin runtime, and coroutines
• R8 won't remove these classes anymore
• Build succeeds! ✅
