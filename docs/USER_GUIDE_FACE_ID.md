
# Guía de Usuario: Face ID y Autenticación

## 🔐 Inicio de Sesión Rápido con Face ID

### ¿Qué es Face ID?

Face ID te permite iniciar sesión en BarLive de forma rápida y segura usando el reconocimiento facial de tu iPhone o la huella digital de tu dispositivo Android.

### Beneficios

- ⚡ **Rápido**: Inicia sesión en menos de 1 segundo
- 🔒 **Seguro**: Tus credenciales están encriptadas en tu dispositivo
- 🎯 **Conveniente**: No necesitas recordar tu contraseña
- 🛡️ **Privado**: Tus datos biométricos nunca salen de tu dispositivo

---

## 📱 Cómo Configurar Face ID

### Paso 1: Inicia Sesión Normalmente

1. Abre BarLive
2. Toca "Iniciar Sesión"
3. Ingresa tu email y contraseña
4. Toca "Iniciar Sesión"

### Paso 2: Habilita Face ID

Después de iniciar sesión, verás un mensaje:

```
¿Quieres habilitar Face ID para iniciar sesión 
más rápido la próxima vez?

[Ahora no]  [Habilitar]
```

1. Toca "Habilitar"
2. Confirma con Face ID (o huella digital)
3. ¡Listo! Face ID está configurado

### Paso 3: Usa Face ID

La próxima vez que abras BarLive:

1. Verás el botón "Iniciar sesión con Face ID"
2. Toca el botón
3. Mira tu iPhone (o usa tu huella)
4. ¡Sesión iniciada!

---

## 🔧 Configuración

### Requisitos

**iOS (Face ID / Touch ID)**:
- iPhone X o posterior (Face ID)
- iPhone 5s - iPhone 8 (Touch ID)
- Face ID o Touch ID configurado en Ajustes

**Android (Huella Digital)**:
- Dispositivo con sensor de huella
- Huella digital configurada en Ajustes

### Verificar Configuración

**iOS**:
1. Ve a Ajustes
2. Toca "Face ID y código"
3. Verifica que Face ID esté activado
4. Asegúrate de tener al menos una cara registrada

**Android**:
1. Ve a Ajustes
2. Toca "Seguridad"
3. Toca "Huella digital"
4. Verifica que tengas al menos una huella registrada

## ❓ Preguntas Frecuentes

### ¿Es seguro Face ID?

**Sí, muy seguro**:
- Tus credenciales están encriptadas
- Se almacenan en el Keychain de iOS / Keystore de Android
- Solo se pueden acceder con Face ID
- Nunca se envían a servidores
- Se eliminan al cerrar sesión

### ¿Qué pasa si cambio de teléfono?

Necesitarás configurar Face ID nuevamente en el nuevo dispositivo:
1. Inicia sesión con email y contraseña
2. Habilita Face ID cuando se te pregunte

### ¿Puedo desactivar Face ID?

Sí, en cualquier momento:
1. Ve a tu Perfil
2. Toca "Configuración"
3. Toca "Seguridad"
4. Desactiva "Inicio de sesión con Face ID"

### ¿Qué pasa si Face ID falla?

Siempre puedes usar tu email y contraseña:
1. Toca "Usar contraseña"
2. Ingresa tu email y contraseña
3. Inicia sesión normalmente

### ¿Funciona sin internet?

Sí, Face ID funciona offline:
- Tus credenciales están en tu dispositivo
- No necesitas conexión para autenticarte
- Solo necesitas internet para sincronizar datos

## 🛠️ Solución de Problemas

### Face ID no aparece

**Posibles causas**:
1. Face ID no está configurado en tu dispositivo
2. La app no tiene permiso para usar Face ID
3. Estás usando Expo Go (no soportado)

**Soluciones**:
1. Configura Face ID en Ajustes de iOS
2. Ve a Ajustes > BarLive > Permitir Face ID
3. Descarga la app desde App Store

### Face ID no funciona

**Posibles causas**:
1. Face ID está bloqueado (muchos intentos fallidos)
2. La cámara está cubierta
3. Estás en un lugar muy oscuro

**Soluciones**:
1. Desbloquea con código y vuelve a intentar
2. Limpia la cámara frontal
3. Muévete a un lugar con mejor iluminación
4. Usa "Usar contraseña" como alternativa

### "No se encontraron credenciales"

**Causa**: No has habilitado Face ID todavía

**Solución**:
1. Inicia sesión con email y contraseña
2. Habilita Face ID cuando se te pregunte
3. Intenta nuevamente

## 🔒 Seguridad y Privacidad

### ¿Qué se almacena?

- ✅ Email (encriptado)
- ✅ Contraseña (encriptada)
- ❌ Datos biométricos (nunca se almacenan)

### ¿Dónde se almacena?

- **iOS**: Keychain de iOS (encriptado por hardware)
- **Android**: Keystore de Android (encriptado por hardware)
- **Servidores**: Nada (todo local)

### ¿Quién puede acceder?

- ✅ Tú (con Face ID)
- ❌ Otras apps (aislado)
- ❌ BarLive (no tenemos acceso)
- ❌ Hackers (encriptado por hardware)

### ¿Qué pasa si pierdo mi teléfono?

1. Tus datos están seguros (encriptados)
2. Nadie puede acceder sin tu Face ID
3. Puedes cerrar sesión remotamente (próximamente)
4. Cambia tu contraseña desde otro dispositivo

## 💡 Consejos

### Para Mejor Experiencia

1. **Mantén Face ID actualizado**
   - Registra tu cara con y sin gafas
   - Actualiza si cambias de look

2. **Usa contraseña fuerte**
   - Face ID es seguro, pero tu contraseña también importa
   - Usa al menos 8 caracteres
   - Combina letras, números y símbolos

3. **Cierra sesión en dispositivos compartidos**
   - No habilites Face ID en dispositivos compartidos
   - Cierra sesión cuando termines

4. **Mantén tu dispositivo actualizado**
   - Actualiza iOS/Android regularmente
   - Actualiza BarLive cuando haya nuevas versiones
