## 🎓 Glosario

**Términos Técnicos:**

- **Edge Function**: Función serverless que se ejecuta en el borde de la red
- **Token**: Código único y temporal para autenticación
- **Hash**: Fragmento de URL después del símbolo #
- **RLS**: Row Level Security - Seguridad a nivel de fila en la base de datos
- **SMTP**: Simple Mail Transfer Protocol - Protocolo para envío de emails
- **DNS**: Domain Name System - Sistema de nombres de dominio
- **SPF**: Sender Policy Framework - Marco de política del remitente
- **DKIM**: DomainKeys Identified Mail - Correo identificado con claves de dominio
- **DMARC**: Domain-based Message Authentication - Autenticación de mensajes basada en dominio
