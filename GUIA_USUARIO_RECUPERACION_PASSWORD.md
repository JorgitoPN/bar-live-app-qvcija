
# Guía de Usuario: Recuperación de Contraseña - Barlive

## 🔐 ¿Olvidaste tu contraseña?

No te preocupes, recuperar tu contraseña es muy fácil. Solo sigue estos pasos:

## 📱 Paso a Paso

### 1️⃣ Solicita tu código

1. En la pantalla de inicio de sesión, toca **"¿Olvidaste tu contraseña?"**
2. Ingresa tu correo electrónico
3. Toca el botón **"Enviar código"**
4. Recibirás un mensaje confirmando que el código fue enviado

**⏱️ Tiempo estimado:** 30 segundos

### 2️⃣ Revisa tu correo

1. Abre tu aplicación de correo electrónico
2. Busca un correo de **Barlive** (noreply@barliveapp.es)
3. El asunto será: **"Código de recuperación de contraseña - Barlive"**
4. Encontrarás un código de **6 dígitos** en grande

**💡 Consejo:** Si no ves el correo, revisa tu carpeta de spam o correo no deseado.

### 3️⃣ Introduce el código

1. En la app, toca **"Continuar"**
2. Verás 6 casillas para ingresar el código
3. Escribe los 6 dígitos que recibiste por correo
4. El código se validará automáticamente
5. Toca **"Validar código"**

**⚠️ Importante:** El código expira en **15 minutos**. Si expira, puedes solicitar uno nuevo.

### 4️⃣ Crea tu nueva contraseña

1. Ingresa tu nueva contraseña
2. Confírmala escribiéndola de nuevo
3. Asegúrate de que cumple con los requisitos:
   - Mínimo 8 caracteres
   - Al menos una letra mayúscula
   - Al menos una letra minúscula
   - Al menos un número
4. Toca **"Actualizar contraseña"**

**✅ ¡Listo!** Tu contraseña ha sido actualizada.

### 5️⃣ Inicia sesión

1. Serás redirigido automáticamente a la pantalla de inicio de sesión
2. Ingresa tu correo electrónico
3. Ingresa tu **nueva contraseña**
4. Toca **"Iniciar sesión"**

**🎉 ¡Bienvenido de vuelta a Barlive!**

## ❓ Preguntas Frecuentes

### ¿Cuánto tiempo tarda en llegar el correo?

Normalmente llega en menos de 1 minuto. Si no lo recibes:
- Revisa tu carpeta de spam
- Verifica que escribiste bien tu correo
- Espera 2-3 minutos más
- Si aún no llega, solicita un nuevo código

### ¿Qué hago si el código expiró?

No hay problema:
1. Vuelve a la pantalla anterior
2. Toca **"Solicitar nuevo código"**
3. Recibirás un nuevo código por correo
4. El código anterior dejará de funcionar

### ¿Puedo usar el mismo código varias veces?

No. Cada código solo puede usarse **una vez**. Después de cambiar tu contraseña, el código se invalida automáticamente.

### ¿Qué hago si ingresé un código incorrecto?

Puedes intentar de nuevo:
- Verifica que copiaste bien el código del correo
- Asegúrate de que no haya espacios
- Si sigues teniendo problemas, solicita un nuevo código

### ¿Es seguro este sistema?

Sí, muy seguro:
- Los códigos expiran en 15 minutos
- Solo pueden usarse una vez
- Se envían a tu correo electrónico verificado
- Nadie más puede ver tu código
- Todo el proceso está encriptado

### ¿Qué hago si no recuerdo mi correo electrónico?

Si no recuerdas el correo con el que te registraste:
- Intenta con todos los correos que uses habitualmente
- Revisa tus correos antiguos de Barlive
- Contacta con soporte: soporte@barliveapp.es

### ¿Puedo cambiar mi contraseña sin código?

No. Por seguridad, necesitas el código que se envía a tu correo para verificar que eres tú.

### Mi cuenta fue creada con Google, ¿puedo usar este sistema?

Si creaste tu cuenta con Google, primero necesitas configurar una contraseña. La app te guiará automáticamente en este proceso.

## 🆘 ¿Necesitas ayuda?

Si tienes algún problema que no se resuelve con esta guía:

**📧 Email:** soporte@barliveapp.es

**💬 Chat en la app:** Ve a Perfil → Centro de Ayuda

**⏰ Horario de atención:** Lunes a Viernes, 9:00 - 18:00 (hora de España)

## 💡 Consejos de Seguridad

### Crea una contraseña segura:

✅ **Haz:**
- Usa al menos 8 caracteres
- Combina mayúsculas y minúsculas
- Incluye números
- Usa una contraseña única para Barlive
- Considera usar un gestor de contraseñas

❌ **No hagas:**
- Usar tu nombre o fecha de nacimiento
- Usar "123456" o "password"
- Compartir tu contraseña con nadie
- Usar la misma contraseña en varios sitios
- Escribir tu contraseña en lugares visibles

### Protege tu cuenta:

- No compartas tu código de recuperación con nadie
- Si recibes un código que no solicitaste, ignóralo
- Cambia tu contraseña regularmente
- Cierra sesión en dispositivos compartidos
- Mantén tu correo electrónico seguro

## 📝 Resumen Rápido

1. **Solicita código** → Ingresa tu email
2. **Revisa correo** → Busca el código de 6 dígitos
3. **Valida código** → Ingrésalo en la app
4. **Nueva contraseña** → Crea una contraseña segura
5. **Inicia sesión** → Usa tu nueva contraseña

**⏱️ Tiempo total:** 2-3 minutos
