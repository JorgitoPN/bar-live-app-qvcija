¿POR QUÉ ESTA LÍNEA ES CRÍTICA?
═══════════════════════════════════════════════════════════════════════════════

R8 (el minificador de Android) tiene dos tipos de análisis:
1. Análisis de CLASES (-keep class)
2. Análisis de INTERFACES (-keep interface)

El error "Missing class expo.modules.kotlin.runtime.Runtime" ocurre porque:
- Runtime es una INTERFAZ de Kotlin, no una clase
- Las reglas anteriores solo protegían las clases (-keep class)
- R8 eliminaba las interfaces porque no estaban explícitamente protegidas

La línea "-keep interface expo.modules.kotlin.** { *; }" le dice a R8:
"NO ELIMINES ninguna interfaz del paquete expo.modules.kotlin"

Esto incluye:
- expo.modules.kotlin.runtime.Runtime (la interfaz que falta)
- Todas las demás interfaces de Kotlin que Expo necesita
